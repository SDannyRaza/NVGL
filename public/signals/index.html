Learning objectives & laboratory method — transmitted signal and received signal

Learning objectives. Study the generated carrier, PRN and navigation message (lessons 01–07); inspect the full observed-satellite scene at each RINEX epoch (lesson 08); then examine an individual satellite and its measurements (lessons 09–12).

Suggested method. Choose an epoch and open All-Satellite Receiver. Select a compatible RF band to view a modeled combined I/Q signal, then isolate any observed satellite to inspect its code delay, Doppler and navigation data.

Interpretation limits. RINEX stores observables and decoded navigation parameters, not digitized RF samples or the original transmitted navigation bits. Distinct RF bands are simulated separately; receiver waveforms are epoch-anchored reconstructions, not raw recordings.

Academic definitions & PRN terminology
PRNA deterministic pseudo-random ranging sequence assigned to a satellite or signal component.
ChipOne binary element of a spreading/ranging sequence; it is distinct from a navigation data bit.
Chipping rateNumber of code chips transmitted per second.
Code phaseReceiver estimate of where the locally generated code aligns with the received code.
Gold codeSequence family formed from preferred maximal sequences with controlled correlation properties.
Memory codeA published sequence stored explicitly rather than generated solely from a short recurrence.

Scientific boundary: Satellites in different RF bands cannot be coherently added in a single narrowband front-end. Each RF group is simulated separately.
