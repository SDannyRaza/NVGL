Learning objectives & laboratory method — Single point positioning and estimation

Learning objectives. Trace pseudorange observations through satellite positions, clock corrections and iterative least squares to a receiver solution.

Suggested method. Start with one epoch; inspect satellite availability, residuals and convergence. Compare correction cases with the same epoch and elevation mask and report units and reference coordinates.

Interpretation limits. Residuals, DOP and coordinate error describe different quantities. A coordinate difference is an accuracy estimate only when the reference position is independently established.

Why does this calculation matter?

ENU rotates each position difference into east, north and up at a fixed reference. RMSE includes bias; standard deviation measures spread about the mean. An approximate header coordinate provides relative differences, not independently verified absolute accuracy.

Student mode

GNSS SPP Laboratory Task

Use the loaded RINEX Observation and Navigation files to solve GPS-only and multi-constellation SPP epoch by epoch. Explain the broadcast satellite coordinates and pseudorange equations, inspect the complete least-squares solution, and compare the successive correction cases.

  1. Export a worked epoch: pseudorange, satellite ECEF, initial receiver, ranges, H, misclosures, least-squares updates, final ECEF and latitude/longitude/height.
  2. Compare GPS and multi-GNSS clock states, satellite counts, DOP and residuals.
  3. Calculate all epochs; report scatter, map, mean ENU, standard deviations and RMSE with the reference provenance.
  4. Compare satellite clock, ionosphere, troposphere and full implemented-model cases. Explain changes that do not improve a particular epoch.
  5. Describe model limitations and the error budget. Multipath and receiver noise: Not directly separable from this dataset.
Why does this calculation matter?

Reproducing one epoch connects each mathematical operation to its physical observation. Comparing many epochs helps distinguish a persistent bias from measurement scatter.

Academic basis: gnss positioning.pdf and gnss positioning with errors 1.pdf supplied with this package. Supplementary model references: ESA Klobuchar equations · RTKLIB broadcast-model reference. Current solver: equal-weight code least squares; no carrier-phase positioning or deterministic multipath/noise correction.
