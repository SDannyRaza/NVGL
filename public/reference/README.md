# Academic references bundled with the VGL

These files are included as teaching/reference material for the frontend-only dashboards.

- `front_end/GNSS_Front_End_Lecture_NCGSA.pptx` — GNSS front-end lecture material.
- `acquisition/gnssacquisition.pdf` — supplied acquisition chapter.
- `acquisition/acquisition.m`, `acquisition_3d.m`, `generateCAcode.m`, `initSettings.m` — supplied SoftGNSS/Kai Borre-style reference code.
- `tracking/GNSS_Tracking.pdf` — supplied carrier/code tracking chapter.
- `tracking/tracking.m`, `plotTracking.m` — supplied reference tracking code.

The deployed application does not run MATLAB or a server backend. These files support academic traceability; interactive scientific calculations execute in the browser.
