Learning objectives & laboratory method — Reading GNSS observation and navigation records

Learning objectives. Interpret file headers, epoch records and observation identifiers; distinguish pseudorange (m), carrier phase (cycles), Doppler (Hz) and signal strength.

Suggested method. Inspect the header before selecting an epoch and satellite. Connect each interpreted field to its original fixed-width record and document missing observations.

Interpretation limits. Observation availability and navigation coverage differ. Missing values must not be interpreted as zero; RINEX navigation parameters are decoded broadcast information.

Suggested Inspection Procedure

1. Inspect receiver, antenna and reference-position metadata.
2. Establish the measurement order from SYS / # / OBS TYPES.
3. Compare C, L, D and S observations at a selected epoch.

Observation Record Format
Each observation occupies 16 character positions: a 14-character value, a one-character loss-of-lock indicator slot and a one-character signal-strength indicator slot. Blank values indicate that no measurement is supplied.

Record Structure

Observation columns follow each constellation’s header definition. Navigation record layouts differ between orbital-parameter and state-vector representations.

Measurement Interpretation

Blank values indicate missing data. Loss-of-lock flags and compact strength indicators are separate from the measured observation values.

Format Reference

Field descriptions refer to RINEX 3.02. Consult the IGS specification for complete definitions, units and constellation-specific conventions.

Interface Reference

The selected observation or navigation file is displayed with its original field spacing. The numeric gutter shows source line numbers.

  • Hover over a field to display its definition and units.
  • Select a field to retain the explanation in the side panel.
  • Use Tab and Enter for keyboard field selection. Esc releases a pinned definition.
  • Press / to focus text search. Search applies to the selected section; choose Full file to search the complete file.
  • Focus view hides the banner and reference panels to expand the inspection area.
  • Export displayed lines saves only the current page as a text excerpt, not a complete RINEX file.
