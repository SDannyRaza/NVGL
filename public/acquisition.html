LESSON 01 / 09

Acquisition Overview

Acquisition answers two initial synchronization questions: Which satellite signal is present? and where is it located in code delay and carrier frequency?

(τ̂, f̂D) = arg max |Rr,c(τ,fD)|²
AcquisitionCoarse synchronization stage that detects a known GNSS ranging code in noisy sampled data.
Code phase (τ)Relative delay between the received PRN sequence and the receiver's local replica.
Doppler (fD)Carrier-frequency offset caused mainly by satellite-receiver relative motion and receiver oscillator error.

LESSON 04 / 09

What is a two-dimensional search?

A satellite’s code is known, but its arrival time and carrier-frequency offset are not. For one selected satellite, acquisition tries pairs of code delay and Doppler frequency. A pair is one hypothesis; its correlation power is one cell in the search map.

Horizontal axis · code delay τShift the local code through one full period. The teaching grid advances one chip at a time; a receiver can use finer sample delays.
Vertical axis · Doppler fTest a frequency interval around the expected carrier. The bin spacing determines how finely this interval is sampled.
Cell colour · correlation powerBoth replicas must align to produce a strong peak. Correct delay with wrong frequency still loses correlation.

Why do grid spacing and observation time matter?

For residual frequency error Δf over a coherent observation T, the ideal power response follows sinc²(πΔfT), where sinc(x) = sin(x)/x. Longer observations narrow the peak, so the Doppler grid must also be sufficiently fine. A code delay is periodic: acquisition estimates alignment within the code period, not an unambiguous geometric range.

LESSON 05 / 09

Serial Search Acquisition

Evaluate one candidate code phase and one candidate Doppler bin at a time. The method is conceptually simple but computationally expensive because the full two-dimensional search grid is visited sequentially.

Ntests = Nτ × Nf
FOLLOW THE SIGNAL

One hypothesis → one correlation value

  1. Choose one delay τ and one carrier frequency. Multiply the samples by the shifted local code to despread the candidate signal.
  2. Mix with cosine and negative sine to form in-phase (I) and quadrature (Q) branches. Sum each branch over the observation, then form I² + Q²; this removes dependence on an unknown constant carrier phase.
  3. Store the power in one search cell. Advance the delay, then the Doppler frequency, until the grid is covered.
Z(τ,f) = |Σ r[n] c[n−τ] exp(−j2πfnTₛ)|²
Resolution, assumptions and computational cost

Each repetition costs roughly N sample multiplications and additions. For the GPS teaching example, 1,023 delays × 41 frequencies = 41,943 direct correlations. A real receiver may stop early after a reliable detection.

LESSON 06 / 09

Parallel Frequency Space Search

Hold one code-phase hypothesis, remove the candidate PRN, and transform the despread signal to the frequency domain. A spectral peak identifies the residual carrier frequency for a correctly aligned code.

X[k] = FFT{x[n] · c[n−τ̂]}
FOLLOW THE SIGNAL

One code delay → a column of frequency hypotheses

  1. Hold one code delay and multiply the input by that local code. If the code aligns, despreading concentrates the signal energy near its carrier frequency.
  2. A Fourier transform evaluates many frequency hypotheses together. Take magnitude squared and retain the frequencies inside the requested search band.
  3. Repeat for every code delay. The delay loop remains; the explicit frequency loop is replaced by a transform.
Z(τ,k) = |Fourier{r[n] c[n−τ]}[k]|²
Resolution, assumptions and computational cost

For an observation lasting T seconds, the natural transform-bin spacing is 1/T Hz: a 1 ms record gives 1 kHz. A 500 Hz evaluation grid requires zero-padding or equivalent interpolation; zero-padding samples the spectrum more finely but does not improve physical resolution. The displayed spectrum is an analytical response, not a measured transform.

Despread frequency response at the matching code delay

LESSON 07 / 09

Parallel Code Phase Search

Use the FFT correlation theorem to evaluate all code phases simultaneously for each Doppler bin. This is the acquisition structure used by the uploaded MATLAB receiver and is also central to GNSS-SDR GPS L1 C/A implementations.

R[τ] = IFFT{FFT{x[n]} · FFT{c[n]}*}
FOLLOW THE SIGNAL

One Doppler hypothesis → a row of code delays

  1. Hold one Doppler hypothesis and mix with exp(−j2πfnTₛ). This complex oscillator combines the cosine and negative-sine branches of the quadrature diagram.
  2. Transform the mixed samples. Multiply by the complex conjugate of the local-code spectrum, then apply an inverse transform to obtain circular correlation at every sample delay.
  3. Square the magnitude and store a full row. Repeat for each Doppler bin; the code spectrum can be reused.
R(τ,f) = Inverse Fourier{Fourier{x_f[n]} · conjugate(Fourier{c[n]})}
Resolution, assumptions and computational cost

Circular correlation assumes a periodic local code and compatible processing blocks. Transform length sets the number of sample-delay outputs; these are not the same as the number of chips. The 1,023-delay comparison uses a one-chip teaching grid. A sampled implementation can evaluate many more delays per row.

Rows combine into the acquisition map

LESSON 08 / 09

See how the search repetitions change

All three methods cover the same delay–frequency space. They differ in how much of that space one repetition evaluates. Fewer repetitions do not mean the same reduction in runtime: a transform costs more than one direct correlation.

Scale the same idea to the real hypothesis counts

Counts compare complete sweeps on the same one-chip delay grid. They exclude early stopping, extra satellites, repeated observations, setup and data transfer. A Fourier operation computes a vector, so repetition counts are not execution-time measurements.

Predict, change, explain · classroom exercise

Start with GPS L1 C/A, ±10 kHz and 500 Hz spacing: 1,023 delays × 41 frequencies. Predict what happens when spacing changes to 250 Hz, then update the workbench. There are now 81 bins: serial search needs 82,863 cell evaluations, parallel frequency search still repeats 1,023 times, and parallel code phase search repeats 81 times. Explain why only the latter two counts respond differently.

Let N be samples per observation. Approximate costs are O(Nτ Nf N) for direct serial correlation, O(Nτ N log N) for parallel frequency search, and O(Nf N log N) for parallel code phase search. Padding and resampling affect actual transform lengths.
