Learning objectives & laboratory method — Broadcast ephemeris and reference frames

Learning objectives. Explain how broadcast parameters produce satellite coordinates and how ECEF, ECI and local ENU frames support different analyses.

Suggested method. Select an epoch and satellite; inspect the broadcast record, coordinate transformation and sky geometry. Report the frame, time system, units and elevation mask with each result.

Interpretation limits. Broadcast orbit propagation has a validity interval. Frame transformations and displayed tracks inherit the implemented model assumptions; DOP describes geometry rather than measured positioning accuracy.

Geometry chain

ECEF to ECI

rECI = R3(θGMST) rECEF

with R3(θ) = [[cosθ, −sinθ, 0], [sinθ, cosθ, 0], [0, 0, 1]]. The dashboard rotates the ECEF state by Greenwich mean sidereal time to obtain an inertial orbit view.

ECEF line-of-sight to local ENU

[E N U]T = R(φ, λ) · (rsat − rrx)

where R(φ, λ) is the standard longitude/latitude rotation matrix from ECEF to East-North-Up coordinates. The receiver point comes from APPROX POSITION XYZ.

Azimuth and elevation

Az = atan2(E,N),   El = atan2(U, √(E²+N²))

Azimuth is measured clockwise from North and normalized to 0–360°. Elevation is measured upward from the local horizon and compared with the selected mask angle.

Dilution of precision

Hi = [−ux −uy −uz 1],   Q = (HTH)−1

GDOP, PDOP and TDOP are derived from Q. The 3×3 position block is rotated into ENU to obtain HDOP and VDOP. The worked values below are derived from the visible satellites at the selected epoch.
